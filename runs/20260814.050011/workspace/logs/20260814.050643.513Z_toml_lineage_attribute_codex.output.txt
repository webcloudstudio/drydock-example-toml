<requirement name="go-parser-architecture" stories="architecture">
The implementation language is Go, fixed by this Target's `TECHNOLOGY_STACK.md` and governed by `stack/go.md`.
</requirement>
<requirement name="stdin-tagged-json-contract" stories="decoder-contract">
The program is a filter: read TOML from **stdin**, write tagged JSON to **stdout**, exit `0`.
</requirement>
<requirement name="reject-invalid-toml" stories="decoder-invalid-input">
On invalid TOML, write a diagnostic to **stderr** and exit non-zero.
</requirement>
<requirement name="tagged-json-encoding" stories="decoder-tagged-json">
Every TOML **value** becomes `{"type": "<TOML_TYPE>", "value": "<TOML_VALUE>"}`.
</requirement>
