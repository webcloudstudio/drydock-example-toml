FEATURE: Table Redefinition

FieldValue
Version20260814 V1
DescriptionRejects conflicting redefinitions among TOML values, standard tables, inline tables, and arrays.
Depends OnFEATURE-Standard-Tables.md, FEATURE-Key-Semantics.md
Providestable-definition validation
ConsumesTOML standard tables, key-definition validation

Behavior

The parser tracks each table and value definition. It rejects duplicate standard-table headers and conflicts that attempt to reinterpret a scalar, inline table, standard table, or array as another structure.
