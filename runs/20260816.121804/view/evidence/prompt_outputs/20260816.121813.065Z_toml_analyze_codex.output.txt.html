# COMPASS: TOML 1.0.0 Parser

## Compass
Build a Go command-line filter that parses TOML 1.0.0 documents and emits the required tagged JSON representation. It serves the supplied conformance harness and downstream programs that need deterministic TOML decoding.

## Constraints
- Implement the parser in Go using only the standard library.
- Preserve the `cmd/toml-decoder` build path and stdin/stdout/stderr contract.
- Support TOML 1.0.0 syntax and semantics described by the supplied specification.
- The decoder takes no arguments and has no configuration or runtime side effects.
- The supplied harness is version-pinned and must be run unfiltered for final acceptance.

## Guardrails
- Never import a third-party TOML parser.
- Never modify, filter, skip, or reinterpret supplied scoring scripts.
- Reject invalid TOML with a diagnostic on stderr and a non-zero exit.
- Emit no successful result or diagnostic on the wrong stream.
- Preserve values losslessly within the TOML requirements, including signed 64-bit integers.
