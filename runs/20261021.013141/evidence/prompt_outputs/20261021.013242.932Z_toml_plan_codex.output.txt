# ARCHITECTURE: TOML Decoder Architecture

| Field       | Value |
|-------------|-------|
| Version     | 20261021 V1 |
| Description | Standard-library-only Go architecture for the TOML 1.0.0 decoder. |
| Depends On  | — |
| Provides    | Go module, cmd/toml-decoder, internal/toml |
| Consumes    | — |

## Questions

- None.

## Purpose

The project is a Go command-line filter that parses TOML 1.0.0 from standard input and emits the required tagged JSON representation to standard output.

## Modules and Boundaries

| Module | Responsibility |
|---|---|
| `cmd/toml-decoder` | Process startup, stdin reading, parser delegation, JSON encoding, diagnostics, and exit status. |
| `internal/toml` | TOML lexical analysis, parsing, document structure, semantic validation, and tagged values. |

The command package must not contain TOML parsing logic. The parser package must use only the Go standard library and must not read files, environment configuration, or external services.

## Interface

The executable accepts no required arguments. It reads the complete TOML document from stdin.

Valid input produces one JSON document on stdout and exits zero. Invalid input produces a diagnostic on stderr, no decoded JSON on stdout, and exits non-zero.

## Technology Stack

- Go 1.22 or newer, governed by `go.md`.
- POSIX shell support for the supplied harness, governed by `common.md`.
- Go module dependencies are restricted to the standard library; `go.mod` declares no `require` dependencies.

## Module Ownership

| Boundary | Owner | Allowed access |
|---|---|---|
| Process startup and streams | `cmd/toml-decoder` | `os`, `io`, `encoding/json`, and `internal/toml` |
| TOML parsing | `internal/toml` | Go standard-library parsing and validation packages |
| Persistence | None | The decoder has no persistent state. |
| Configuration | None | The decoder reads no configuration files or environment settings. |
| File store | None | The decoder reads only stdin. |
| External services | None | The decoder has no external service calls. |

# FEATURE: Decoder Contract

| Field       | Value |
|-------------|-------|
| Version     | 20261021 V1 |
| Description | Defines the stdin, tagged-JSON, diagnostic, and exit-status contract for the TOML decoder. |
| Depends On  | ARCHITECTURE.md |
| Provides    | stdin TOML decoder, tagged JSON stdout, stderr diagnostics |
| Consumes    | Go module, cmd/toml-decoder |

## Questions

- None.

## Purpose

Provide a deterministic command-line filter for TOML input. The command delegates parsing to `internal/toml` and serializes the resulting tagged representation as JSON.

## Contract

- Tables encode as JSON objects.
- Arrays encode as JSON arrays.
- Every TOML scalar value encodes as an object with `type` and string-valued `value` fields.
- Supported type tags are `string`, `integer`, `float`, `bool`, `datetime`, `datetime-local`, `date-local`, and `time-local`.
- Valid input emits JSON only on stdout and exits zero.
- Invalid input emits a diagnostic on stderr, emits no decoded output, and exits non-zero.
- The command takes no arguments, reads no configuration files, and produces no side effects.

# FEATURE: Parser Strings

| Field       | Value |
|-------------|-------|
| Version     | 20261021 V1 |
| Description | Parses TOML basic, literal, and multiline string forms according to TOML 1.0.0. |
| Depends On  | FEATURE-Decoder-Contract.md |
| Provides    | TOML string parsing |
| Consumes    | stdin TOML decoder |

## Questions

- None.

## Scope

Implement basic strings, multiline basic strings, literal strings, and multiline literal strings.

The parser must support valid escapes, Unicode scalar escapes, multiline newline trimming, line-ending backslashes, literal preservation, delimiter rules, and the control-character restrictions defined by TOML 1.0.0. String values must retain the required decoded content in tagged JSON.

- None.

## Guardrails

- Reject prohibited control characters.
- Preserve literal-string backslashes and content without interpreting escapes.
- Do not permit unterminated or malformed string delimiters.
