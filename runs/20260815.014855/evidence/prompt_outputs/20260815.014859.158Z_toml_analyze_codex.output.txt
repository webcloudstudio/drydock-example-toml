## Planning Instructions

### Delivery Shape

Deliver a standard-library-only Go command-line filter. It accepts a UTF-8 TOML document on stdin, parses it into an internal document model, emits tagged JSON on stdout, and reports invalid input on stderr with a non-zero exit. The supplied shell scripts and `toml-test` corpus provide staged acceptance execution.

### Test and Acceptance Strategy

Foundation stories use `sources/stage_contract.sh`. Lexical and structure stories run only their corresponding bounded `toml-test` slices through `sources/stage_test.sh` and declare `Suite: scoped`. CONFORMANCE-001 is the sole terminal verification story, depends on every implementation story, declares `Suite: full`, and runs `sh sources/full_test.sh`.

### Sequencing and Dependencies

Build FOUNDATION-001 before all tests. Implement FOUNDATION-002 before parser slices. Parser lexical behavior precedes structural semantics; all parser stories precede CONFORMANCE-001. The staged harness scripts must remain unchanged. `toml-test` v2.2.0 must be installed before conformance execution.

# COMPASS: TOML Parser

## Compass

This project delivers a command-line TOML v1.0.0 parser for automated callers. It reads one TOML document from standard input and emits a tagged JSON representation, while rejecting malformed documents with a diagnostic and non-zero exit. Correctness is defined by the supplied upstream conformance suite.

## Constraints

- Implement the parser in Go.
- Use only the Go standard library; no third-party TOML parser.
- Preserve the fixed `cmd/toml-decoder` build entry point.
- Keep stdin, stdout, stderr, and exit-status behavior compatible with the supplied contract.
- Support TOML v1.0.0 behavior described by the supplied specification.
- Do not require network access during test execution after harness setup.

## Guardrails

- Do not modify supplied scoring or conformance scripts.
- Do not skip, filter, reinterpret, or replace the complete conformance verdict.
- Reject invalid TOML rather than accepting permissive extensions.
- Preserve tagged JSON value types and string-valued representations.
