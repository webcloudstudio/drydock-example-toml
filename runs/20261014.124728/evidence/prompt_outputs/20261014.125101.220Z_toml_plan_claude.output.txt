# FEATURE: Parser Keys

| Field       | Value |
|-------------|-------|
| Version     | 20261014 V1 |
| Description | Bare, quoted, and dotted key forms, and the key-definition rules that reject redefinition. |
| Depends On  | ARCHITECTURE.md, FEATURE-Parser-Strings.md, FEATURE-Parser-Lexical-Scalars.md |
| Provides    | bare, quoted, and dotted key parsing with redefinition checks |
| Consumes    | None |

## Questions

- None.

## Purpose

Parse bare keys (`A-Za-z0-9_-`), quoted keys (basic or literal strings), and dotted keys that create intermediate tables. Reject defining the same key twice. A bare key and a quoted key with the same name are equivalent. A key that holds an integer cannot later be used as a table.

## Programmatic Acceptance

=== AC keys-bare-round-trip ===
Intent: A bare key decodes as the named key with a tagged value.
Requires: executable=go; scope=test

import json
import subprocess
import sys

build = subprocess.run(
    ["go", "build", "-o", "toml-decoder", "./cmd/toml-decoder"],
    capture_output=True, text=True,
)
print(build.stderr, file=sys.stderr)
assert build.returncode == 0

key = "bare-key_1"
value = "5"
source = f"{key} = {value}\n"
result = subprocess.run(["./toml-decoder"], input=source, capture_output=True, text=True)
print(result.stderr, file=sys.stderr)
assert result.returncode == 0
decoded = json.loads(result.stdout)
assert decoded == {key: {"type": "integer", "value": value}}
=== END AC keys-bare-round-trip ===

# FEATURE: Parser Tables

| Field       | Value |
|-------------|-------|
| Version     | 20261014 V1 |
| Description | Standard table headers, implicit super-tables, arrays of tables, and their redefinition and ordering rules. |
| Depends On  | ARCHITECTURE.md, FEATURE-Parser-Keys.md |
| Provides    | table headers and arrays of tables in internal/toml |
| Consumes    | None |

## Questions

- None.

## Purpose

Parse `[table]` headers and `[[array]]` headers. Create implicit super-tables for `[a.b.c]`. Each `[[name]]` header appends a new table element to the array named `name`, and later sub-tables attach to the most recent element. Reject a standard table defined twice, and reject a `[[name]]` header that conflicts with a static table or static array.

## Programmatic Acceptance

=== AC tables-header-round-trip ===
Intent: A standard table header creates a nested table holding its keys.
Requires: executable=go; scope=test

    capture_output=True, text=True,

# FEATURE: Parser Arrays Inline

| Field       | Value |
|-------------|-------|
| Version     | 20261014 V1 |
| Description | Arrays, inline tables, and the closure rule that forbids extending an inline table. |
| Depends On  | ARCHITECTURE.md, FEATURE-Parser-Strings.md, FEATURE-Parser-Lexical-Scalars.md, FEATURE-Parser-Keys.md |
| Provides    | array and inline-table parsing in internal/toml |
| Consumes    | None |

## Questions

- None.

## Purpose

Parse arrays of mixed value types, with nesting, optional trailing comma, and multi-line layout with comments. Parse inline tables on a single line with no trailing comma. An inline table is closed: keys cannot be added to it through dotted keys or table headers.
