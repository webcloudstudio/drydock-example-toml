FEATURE: Parser Strings

FieldValue
Version20261014 V1
DescriptionDecoding of the four TOML string forms: basic, multi-line basic, literal, and multi-line literal.
Depends OnARCHITECTURE.md
Providesstring value decoding in internal/toml
ConsumesNone

Purpose

Decode basic strings with the listed escapes only, multi-line basic strings with newline trimming and the line-ending backslash rule, literal strings with no escaping, and multi-line literal strings. Reject any other backslash escape and any control character not permitted by the specification.

Programmatic Acceptance

=== AC strings-basic-round-trip ===
Intent: A basic string value is decoded and written as a tagged string.
Requires: executable=go; scope=test

import json import subprocess import sys

build = subprocess.run( ["go", "build", "-o", "toml-decoder", "./cmd/toml-decoder"], capture_output=True, text=True, ) print(build.stderr, file=sys.stderr) assert build.returncode == 0

Guardrails
