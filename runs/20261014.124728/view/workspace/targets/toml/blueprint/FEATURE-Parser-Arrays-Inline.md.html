FEATURE: Parser Arrays Inline

FieldValue
Version20261014 V1
DescriptionArrays, inline tables, and the closure rule that forbids extending an inline table.
Depends OnARCHITECTURE.md, FEATURE-Parser-Strings.md, FEATURE-Parser-Lexical-Scalars.md, FEATURE-Parser-Keys.md
Providesarray and inline-table parsing in internal/toml
ConsumesNone

Purpose

Parse arrays of mixed value types, with nesting, optional trailing comma, and multi-line layout with comments. Parse inline tables on a single line with no trailing comma. An inline table is closed: keys cannot be added to it through dotted keys or table headers.

Programmatic Acceptance
