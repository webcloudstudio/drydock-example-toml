FEATURE: Parser Lexical Scalars

FieldValue
Version20261014 V1
DescriptionDecoding of booleans, integers, and floats, with range and form rules from the specification.
Depends OnARCHITECTURE.md
Providesboolean, integer, and float decoding in internal/toml
ConsumesNone

Purpose

Decode booleans, decimal and prefixed integers (0x, 0o, 0b) with underscores, and floats with fractional and exponent parts, plus the special floats inf, nan, and their signed forms. Integers must fit signed 64-bit and are rejected otherwise.

Programmatic Acceptance

=== AC scalars-integer-round-trip ===
Intent: The largest signed 64-bit integer decodes losslessly as a tagged integer.
Requires: executable=go; scope=test

import json import subprocess import sys

build = subprocess.run( ["go", "build", "-o", "toml-decoder", "./cmd/toml-decoder"], capture_output=True, text=True, ) print(build.stderr, file=sys.stderr) assert build.returncode == 0
