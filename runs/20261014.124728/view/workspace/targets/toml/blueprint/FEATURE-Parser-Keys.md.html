FEATURE: Parser Keys

FieldValue
Version20261014 V1
DescriptionBare, quoted, and dotted key forms, and the key-definition rules that reject redefinition.
Depends OnARCHITECTURE.md, FEATURE-Parser-Strings.md, FEATURE-Parser-Lexical-Scalars.md
Providesbare, quoted, and dotted key parsing with redefinition checks
ConsumesNone

Purpose

Parse bare keys (A-Za-z0-9_-), quoted keys (basic or literal strings), and dotted keys that create intermediate tables. Reject defining the same key twice. A bare key and a quoted key with the same name are equivalent. A key that holds an integer cannot later be used as a table.

Programmatic Acceptance
