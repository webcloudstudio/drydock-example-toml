FEATURE: Parser Lexical Boundaries

FieldValue
Version20261014 V1
DescriptionComment syntax, forbidden control characters, and UTF-8 validity of TOML input.
Depends OnARCHITECTURE.md, FEATURE-Parser-Strings.md, FEATURE-Parser-Lexical-Scalars.md
Providescomment handling and control-character and UTF-8 validation
ConsumesNone

Purpose

A hash begins a comment that runs to end of line, except inside a string. Control characters other than tab are rejected in comments and literal strings. Input that is not valid UTF-8 is rejected.

Programmatic Acceptance

=== AC boundaries-comment-round-trip ===
Intent: A trailing comment is ignored and the value before it decodes normally.
Requires: executable=go; scope=test

build = subprocess.run( ["go", "build", "-o", "toml-decoder", "./cmd/toml-decoder"], capture_output=True, text=True, ) print(build.stderr, file=sys.stderr) assert build.returncode == 0
